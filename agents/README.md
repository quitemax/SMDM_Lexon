# agents/

Notatki i instrukcje operacyjne per rola agenta (patrz PROJECT_CONCEPT.md
sekcja 53, AGENTS.md). Nie jest to kod agentów — to dokumentacja zakresu i
zasad pracy każdej roli, czytana przez agenta przed podjęciem zadania danego typu.

```
extraction/      Source Agent — pobieranie, normalizacja, segmentacja tekstu
formalization/   Ontology/Rule Agent — encje, relacje, reguły, warunki, skutki
validation/      Reviewer Agent — pokrycie źródła, sprzeczności, braki
review/          notatki z przeglądów człowieka (human review log)
```
