# normalized/

Tekst aktu podzielony na jednostki normatywne, bez formalizacji
semantycznej — czysta segmentacja. Format: Akoma Ntoso XML, patrz
`akoma-ntoso/`.

Aktualny zasięg (**fragment, nie cała ustawa** - w odróżnieniu od
`law/prawo-spoldzielcze/`): patrz `lexon:coverage` w `<meta><proprietary>`
`akoma-ntoso/ustawa-o-spoldzielniach-mieszkaniowych.xml` (jedno źródło
prawdy, nie duplikowane tutaj). Klucz cytowania `USM-ART-NNN` używany w
`../rules/`, `../procedures/`, `../ontology/` odpowiada
`eId="art_{numer}"` w tym pliku (patrz `docs/dsl.md`,
`akoma-ntoso/README.md`).

Źródło i przypięta wersja: `../source/README.md` (Dz.U. 2026 poz. 889,
stan na 2026-06-10 — **inna data niż Prawo spółdzielcze**, dwa
niezależnie konsolidowane akty).
