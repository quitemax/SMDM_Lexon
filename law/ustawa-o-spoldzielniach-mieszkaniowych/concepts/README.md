`law/prawo-spoldzielcze/concepts/` dla wzorca (`C-PS-0001`, `C-PS-0002`).

normalizacji, patrz `../normalized/`) nie zawiera pojęcia wymagającego
tej kategorii; do rewizji w miarę formalizacji kolejnych fragmentów.
