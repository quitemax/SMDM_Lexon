# concepts/

Pojęcia nieostre (OPEN_TEXTURED), np. "szczególnie uzasadniony przypadek",
"rażące naruszenie" — jawnie oznaczone jako wymagające interpretacji, nigdy
mechanicznie rozstrzygane (patrz PROJECT_CONCEPT.md sekcja 20, AGENTS.md sekcja 9).

Zawiera:

- `C-PS-0001` — "rażące niedbalstwo" (Art. 24 §2), UNRESOLVED.
- `C-PS-0002` — "dobre obyczaje" (Art. 24 §2), UNRESOLVED.

Oba referencjonowane przez `../procedures/R-PS-0016-exclusion-or-strike-off.yaml`
jako podstawy wykluczenia — świadomie NIE sprowadzone do warunku
boolowskiego (patrz AGENTS.md sekcja 9). "Wina umyślna" (ta sama norma)
celowo pominięta — uzasadnienie w
`../normalized/art-024.yaml` (`note_on_scope`).

Dodatkowe pojęcia nieostre zidentyfikowane, ale jeszcze nieutworzone jako
osobne `CONCEPT` (bo odpowiadająca reguła, `R-PS-0005`, nie jest jeszcze
testowana): "uzasadniona obawa", "cele sprzeczne z interesem spółdzielni",
"znaczna szkoda" (Art. 18 §3).
